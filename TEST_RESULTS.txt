Audiophile Player — MDX-Net / Live Karaoke verification

## Current acceptance gate

The repository is wired so the current GitHub Actions pipeline can verify the exact production model and the Android processing path:

1. Verify the vendored ONNX file size and SHA-256.
2. Run a real ONNX Runtime CPU smoke test against that exact binary.
3. Run the JVM streaming/STFT/resampler/Live Karaoke regression suite.
4. Assemble the debug APK and verify the bundled model/native payload.
5. Assemble a deterministic CI-signed release variant and verify its APK signature.
6. Run Android instrumentation on an API-35 emulator covering real bundled-model ONNX Runtime inference, the bounded MDX streaming separator, and exact neural-to-Fast pending-audio handoff continuity.
7. Build the production `release` variant when the four production signing secrets are supplied.

## Current implementation status

- Production neural backend: ONNX Runtime Android + pinned UVR MDX-Net 9482.
- Model distribution: APK-vendored asset only; no runtime network model download.
- Live processing: bounded, progressive, source-rate-aware, AudioTrack-backed.
- Fast fallback: same PCM timeline, no decoder/output restart.
- Pause/resume: gates decode, inference and playback.
- Seek: rebuilds neural context while reusing the cached model session.
- Native DSP shutdown: protected against stop/seek races by inference-worker ownership.
- PEQ and Stereo Widener remain outside the vocal-remover backend.
- No active HT-Demucs model/runtime is present in the current app module.

## Verification caveat

No current GitHub Actions result is being claimed from this review. The repository changes are implemented and the required CI/instrumentation gates are wired, but the latest head still needs an actual GitHub Actions execution and physical-phone acceptance run before it can honestly be marked fully production-verified.

Real-device testing remains required for long songs, thermal throttling, low-memory behavior, pause/resume, seek/stop races, AudioTrack behavior, sustained neural throughput, and subjective vocal-removal quality.
