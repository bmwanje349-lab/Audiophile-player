03 / Repair lab

Build a cautious repair pass

Choose targets, then run the actual FFmpeg engine locally or copy a command for a machine with Python installed.

NON-DESTRUCTIVE SOURCE
Repair configuration
The original file is never overwritten by the CLI defaults.
The engine decides which repairs are justified by measured checks. Loudness changes do not restore detail already lost to clipping or lossy encoding.
Engine launchpad
Deep analysis and repair activate when this page is opened from server.py.
python audio_doctor.py "your-track.mp3" --format mp3 --lufs -14 --true-peak -1.5
How to unlock the Python engine: download this repository, install FFmpeg and NumPy, then run python server.py from the audio-doctor folder. The dashboard will connect automatically at localhost.
GitHub Pages mode stays in your browser and never uploads music. Actual FFmpeg repairs require the local server or the CLI.
